# Курсовой проект "Развертывание, тестирование и мониторинг веб приложения с использованием docker, apache jmeter и zabbix"

## Последовательность развертывания

1. Скачать Debian 13 generic cloud (`wget https://cloud.debian.org/images/cloud/trixie/latest/debian-13-genericcloud-amd64.qcow2`).
2. Подготовить образ к работе с Ansible (установить ssh, python3), развернуть VM. (Если без `virt-sysprep` подобного, то порядок обратный).
3. Осуществить оснастку VM через Anible playbook.
4. Проверить подключение на пропускную способность.
5. Развернуть тестирующую инфраструктуру через Docker.
6. Осуществить тестирование.
7. Сформировать отчёт.

## Используемые технологии

- virt-sysprep/cloud-init: подготовка образа.
- Ansible playbook: развертывание OpenVPN, тестируемого приложения.
- ssh + OpenVPN: подключение.
- Docker/+ Compose: развертывание Apache Jmeter и Zabbix.
- Apache Jmeter: нагрузочное тестирование.
- Zabbix: мониторинг VM.

## От чего пришлось отказаться; Ограничения

- Образ собирается под KVM в формате qcow2. Для работы с VirtualBox и подобными нужна конвертация.
- GitHub CI/CD: необоснованное увеличение сложности. Билды под разные платформы не нужны.
- Тестирование: окупается только при множественных запусках, оные не планируются.

- Vagrant/Packer: высокая зависимость от одного инструмента, сложности с получением Vagrantbox.
